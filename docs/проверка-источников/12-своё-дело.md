# Запись проверки источников главы 12 (07.09.2026)

Способ проверки: лимит WebSearch в этой сессии исчерпан, для поиска нормативных актов использовался поисковый интерфейс базы политических документов портала Правительства КНР (sousuo.www.gov.cn/search-gov/data, использован только для нахождения URL, не как источник). Каждый URL сначала открывался через WebFetch для подтверждения заголовка, номера документа и содержания статей; для страниц с полным текстом закона HTML дополнительно скачивался через curl в scratchpad (s12/page_*.html), теги вырезались, и оригинал дословно находился по номеру статьи «第 X 条» — все цитируемые ниже фрагменты найдены именно так. На странице Министерства трудовых ресурсов и социального обеспечения есть скрипт защиты от скрапинга, WebFetch возвращал пустоту, использован curl с cookie, вычисленным этим скриптом, чтобы получить полный текст (заголовок страницы и строка версии сверены). Сертификат системы франчайзинга Министерства коммерции не соответствует домену, WebFetch выдавал ошибку, использован curl -k, заголовок сверен. DOI через doi.org переадресует на pubsonline.informs.org, которая отдаёт 403, поэтому библиографические данные и аннотация проверены через Crossref API и Semantic Scholar API.
