# Запись проверки источников главы 6

Пояснение к способу проверки: doi.org во всех случаях отдаёт переадресацию 302; страницы издательств JAMA/NEJM/Elsevier/Wiley/ACP/RSNA/Nature на запросы WebFetch отвечают 403, страницы PubMed отдают только уведомление о cookie. Поэтому текст аннотаций единообразно проверялся через официальный REST-интерфейс Europe PMC (`https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:<doi>&resultType=core&format=json`, возвращает те же библиографические данные и abstractText, что и PubMed); в отдельных случаях использован efetch из NCBI E-utilities. «Фактически открытый URL» ниже — это адрес, по которому WebFetch успешно вернул содержимое при проверке. Все DOI один в один соответствуют названию/авторам/году в библиографической записи, которую вернул Europe PMC.
