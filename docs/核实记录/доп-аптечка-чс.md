# Пункт 26 главы 1 «аптечка на случай ЧС» · запись проверки (2026-09-08)

Источник задачи: читатель предложил, что «вещи, обязательные дома, например турникет», не имеют отдельного места в книге. Проверка показала, что турникет уже есть в пункте 4 главы 13, не хватает взгляда именно на список снаряжения: огнетушитель, противопожарное одеяло, эвакуационная дыхательная маска, содержимое аптечки первой помощи — во всей книге ноль упоминаний. По договорённости новую главу не открываем, в конец главы 1 добавлен один пункт, детали — в docs/аптечка-чс.md.

Пояснение об инструментах: в этом заходе доступен WebSearch; API поиска портала Правительства КНР (sousuo.www.gov.cn/search-gov/data) по запросам «запасы бытовых средств на случай ЧС» и «общенациональная статистика пожаров» вернул code 1001 без результатов, вместо этого через WebSearch найдены официальные URL и открыты по отдельности через WebFetch. Сайт Государственного управления пожарно-спасательной службы 119.gov.cn по всему сайту возвращает 412, как и в прошлых записях. Оба PDF-файла со стандартом GB 55036—2022 с государственных сайтов скачаны, но pdftotext извлекает из них только цифры и латиницу — у китайского шрифта нет карты ToUnicode, на этой машине нет pdftoppm для конвертации в изображение, поэтому текст самих норм получить не удалось.

Пояснение к присвоению уровня: пункту присвоен уровень B с пометкой «спорно». Причина в том, что со стороны доказательств пользы есть только этот один обзор Cochrane, доверительный интервал его главного результата захватывает 1, а величина эффекта в группе «без выдачи снаряжения» сопоставима с общей — это говорит о том, что главный источник снижения травматизма не само снаряжение; официальный список — авторитетный документ, но не содержит никакой величины эффекта. Величина выгоды по денежному... то есть по метрике смертности определена по порогу относительного снижения: IRR 0,89 соответствует примерно 11%, что попадает в диапазон 10–20%, отмечено «средняя», не «большая». Цена: комплект за несколько сотен юаней отмечен как деньги=немного, время=немного, воля=нет.
