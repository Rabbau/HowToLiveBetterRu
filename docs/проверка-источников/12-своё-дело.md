# Запись проверки источников главы 12 (07.09.2026)

Способ проверки: лимит WebSearch в этой сессии исчерпан, для поиска нормативных актов использовался поисковый интерфейс базы политических документов портала Правительства КНР (sousuo.www.gov.cn/search-gov/data, использован только для нахождения URL, не как источник). Каждый URL сначала открывался через WebFetch для подтверждения заголовка, номера документа и содержания статей; для страниц с полным текстом закона HTML дополнительно скачивался через curl в scratchpad (s12/page_*.html), теги вырезались, и оригинал дословно находился по номеру статьи (по шаблону «Статья X» на китайском) — все цитируемые ниже фрагменты найдены именно так. На странице Министерства трудовых ресурсов и социального обеспечения есть скрипт защиты от скрапинга, WebFetch возвращал пустоту, использован curl с cookie, вычисленным этим скриптом, чтобы получить полный текст (заголовок страницы и строка версии сверены). Сертификат системы франчайзинга Министерства коммерции не соответствует домену, WebFetch выдавал ошибку, использован curl -k, заголовок сверен. DOI через doi.org переадресует на pubsonline.informs.org, которая отдаёт 403, поэтому библиографические данные и аннотация проверены через Crossref API и Semantic Scholar API.

- Ст. 681: «договор поручительства — это договор, по которому поручитель и кредитор договариваются, что при неисполнении должником наступившего обязательства или наступлении согласованного сторонами обстоятельства поручитель исполняет обязательство или несёт ответственность, в целях обеспечения реализации требования»
- Ст. 687: «если стороны в договоре поручительства договорились, что поручитель несёт ответственность при неспособности должника исполнить обязательство, это обычное поручительство. Поручитель при обычном поручительстве вправе отказаться от исполнения обязательства перед кредитором до тех пор, пока спор по основному договору не рассмотрен судом или арбитражем и принудительное взыскание с имущества должника по закону не показало невозможность исполнения»

При неисполнении должником наступившего обязательства при солидарном поручительстве… кредитор вправе потребовать исполнения от должника либо потребовать от поручителя нести ответственность в пределах его поручительства»
- Ст. 1064: «долг, возникший по совместной подписи супругов либо по последующему одобрению одним из супругов и подобному совместному волеизъявлению… является общим долгом супругов. Долг, взятый одним из супругов лично в период брака сверх потребностей повседневной семейной жизни, не является общим долгом супругов; кроме случаев, когда кредитор может доказать, что долг использован на совместную жизнь, совместную хозяйственную деятельность супругов либо возник на основании их совместного волеизъявления»
